# 安全边界

- **GitHub Actions 是无状态临时机器。** 不通过 Actions 存储或输入邮箱密码、Microsoft/Oracle 密码、短信/邮件验证码、卡号/CVV、学校证明文件、Cookie、Bearer Token、sessionStorage、localStorage。
- **公开仓库可能让运行日志与 Artifact 被任何人看到。** 脚本只访问三个白名单公开页面，展示模拟表单测试，不接触真实用户资料。
- 不使用公开可访问的远程调试端口、VNC 隧道或自建表单采集认证信息。
- 不使用假学校邮箱、虚构身份、借用支付卡、重复申请新用户优惠。
- 测试执行时仅赋予 GitHub Actions `contents: read`，保留 3 天的公开页面截图。不要增加 `secrets: inherit`。
- 若未来需要真实交互式登录，应使用受保护、可让本人接管的浏览器连接，并经过单独的隐私和权限审查。不要把工作流当作有状态远程桌面。
- 创建服务器前先确认规格属于官方免费范围，不能以预算通知取代硬性的付费保护。
